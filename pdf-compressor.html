Important: No browser tool can guarantee a smaller file for every PDF. Already-optimized PDFs may stay the same size or become larger. Image-based modes flatten each page into a picture, so text will no longer be searchable/selectable and forms, links, bookmarks, layers and signatures may not survive. Password-protected or damaged PDFs may not open. Very large files can require substantial device memory.

Which mode should I choose?

Start with Balanced for scanned or image-heavy files. Choose Smart when you need selectable text, vector artwork or better accessibility.

Why didn't the size shrink?

Some PDFs already contain compressed images and optimized streams. Rewriting them cannot always save bytes; try a careful image-based mode only if flattening is acceptable.

Does my file leave my device?

PDF parsing and output generation run locally in this browser. The page loads its PDF libraries from a public CDN; the PDF itself is not sent to that CDN.
