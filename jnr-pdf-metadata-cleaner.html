Scope & limitations
What deep cleaning means here.
This rebuild is designed to remove source-document metadata and non-visible PDF structures by not importing them. Metadata scanners can only report what PDF.js exposes; unusual or malformed files may contain objects it does not surface. The new PDF still has ordinary structural data required to display pages, and its output file name remains visible to the operating system.
