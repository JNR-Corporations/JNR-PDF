JNR Image to PDF guide

Build a PDF from a large image batch
  • Select multiple images together, or drag them from your file manager into the page.
  • Move cards by dragging. Use rotate buttons to correct orientation, and remove any page you do not need.
  • Auto-enhance gently balances brightness and contrast. Clarity mode uses a light sharpening pass; use modest settings to avoid halos.
  • Each image becomes one page. Automatic orientation follows each image's shape unless you choose portrait or landscape.
  • For hundreds of pages, use Standard/High resolution and Balanced/High quality first. Ultra resolution and maximum JPEG quality need more memory and create much larger files.
Compatibility
Images are processed locally. Direct PDF download uses jsPDF loaded from a CDN, so an internet connection is needed for that library. GIFs generally export as a still frame, depending on browser decoding. Some device-specific formats such as HEIC may not be supported by your browser.
