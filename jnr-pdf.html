JNRML command handbook

JNR Markup Language · Commands work in the live PDF terminal.

JNRML quick start: type normal text directly, or use /h1 Your title. Paired styles use a slash opener and a backslash closer. Search commands in the Command Deck, type / for live autocomplete, press Tab to accept a suggestion, and use Ctrl+K to open the command search.
Advanced layout: /margin 18 sets all page margins in millimetres; /margin 18 14 20 14 sets top/right/bottom/left. /padding 24px 28px sets inner page padding. Tables support sizing with /table 4x3 plus independent width, cell padding and colours. The legacy typo /tbale remains supported.
